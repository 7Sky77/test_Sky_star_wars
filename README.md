# Sky Star Wars (test_Sky_star_wars)

Браузерная космическая стратегия в духе OGame / XCraft. Сейчас в разработке фракция **«Люди» (terran)**.

Репозиторий: [github.com/7Sky77/test_Sky_star_wars](https://github.com/7Sky77/test_Sky_star_wars)

## Где лежит проект

**Рабочая копия на компьютере:**

```
C:\Users\user\Documents\Sky star wars\test_Sky_star_wars
```

**Корень репозитория** — папка, где лежат `package.json`, `apps/`, `content/`, `packages/`.

> В репозитории осталась вложенная папка `test_Sky_star_wars/` — это старая копия с ранних загрузок. **Не запускайте проект из неё.** Используйте только корень репозитория.

## Быстрый старт (разработка)

Из корня репозитория:

```bash
npm install
npm run dev
```

Откройте в браузере:

| Сервис | URL |
|--------|-----|
| Игра (клиент) | http://localhost:5175/ |
| API (сервер) | http://localhost:3001/ |

Клиент проксирует `/api` и `/auth` на сервер через Vite — отдельно API в браузере открывать не нужно.

### Windows (PowerShell / cmd)

```cmd
npm.cmd install
npm.cmd run dev
```

## Сборка и продакшен

```bash
npm run build
npm start
```

По умолчанию сервер слушает `0.0.0.0:3001`. Статику web после `npm run build -w apps/web` можно раздавать любым HTTP-сервером из `apps/web/dist/` (в MVP основной сценарий — `npm run dev`).

## Структура monorepo

```
apps/
  server/     Fastify + SQLite, игровой движок, API
  web/        Vite + React, интерфейс игрока
packages/
  shared/     схемы Zod, формулы экономики и боя
content/      JSON-каталог: здания, флот, оборона, исследования, мир
data/         SQLite-база (создаётся локально, в git не попадает)
```

## Переменные окружения (сервер)

| Переменная | По умолчанию | Назначение |
|------------|--------------|------------|
| `PORT` | `3001` | Порт API |
| `JWT_SECRET` | `dev-insecure-change-me` | Подпись токенов |
| `DATABASE_PATH` | `data/game.db` | Путь к SQLite |
| `ADMIN_USERNAMES` | `Sky` | Логины с доступом в админку (через запятую) |
| `ADMIN_PANEL` | вкл. вне production | `1` — принудительно включить админку |
| `ALLOW_RESOURCE_CHEAT` | вкл. вне production | `1` — тестовая выдача ресурсов через API |

## Переменные окружения (web)

| Переменная | Назначение |
|------------|------------|
| `VITE_ALLOW_RESOURCE_CHEAT=true` | Показать панель «Поставка ресурсов (тест)» в production-сборке |

В dev (`vite`) панель видна и без этой переменной, если на сервере включены читы.

## Админка и каталог

В режиме разработки доступна админ-панель (редактирование `content/*.json` через UI). Пользователи из `ADMIN_USERNAMES` получают флаг `is_admin` при регистрации/логине.

При правке JSON в dev каталог **перечитывается с диска** при обновлении страницы или запросе `/api/catalog` — перезапуск сервера не обязателен.

## Игровой мир (кратко)

- Координаты: `[рукав:система:слот]`, рукав и система **1…50**, слот **0** — звезда, **1…9** — планеты.
- Ресурсы: металл, минералы, веспен, энергия.
- Специализация юнитов задаётся в каталоге (`content/units.json`, `content/defense.json`) — множители урона по размеру и типу брони цели.
