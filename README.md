# test_Sky_star_wars

Запуск из этой папки: `npm.cmd install` затем `npm.cmd run dev`. Браузер: http://localhost:5173/

**Тестовая поставка ресурсов:** в шапке игры раскрой «Поставка ресурсов (тест)», введи суммы и «Начислить». На сервере включено при `NODE_ENV !== production` или при `ALLOW_RESOURCE_CHEAT=1`. Во фронте панель видна в dev (`vite`) или если задано `VITE_ALLOW_RESOURCE_CHEAT=true` в `.env` у web.
