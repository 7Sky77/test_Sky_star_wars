# Спрайты планет (гибрид)

- **Базы** (`bases/{type}.png`) — AI-иконки по одному на тип (8 шт.).
- **Варианты** — генерируются скриптом: яркость, насыщенность, tint, поворот ±18°.

## Регенерация

```bash
npm install
npm run generate:planets
```

Выход: `apps/web/public/assets/planets/{type}/{0-9}.png` (80 файлов).

Замените `bases/*.png`, чтобы обновить стиль всего набора.
